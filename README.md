# DSA in Java

My Java practice repository for data structures and algorithms — from language fundamentals to classic interview problems.

## Contents

| Topic | Files |
| --- | --- |
| Basics | `hello_world`, `sum`, `mult`, `average`, `even`, `prime`, `fact`, `swap`, `binomial`, `binary_decimal`, `palindrome_number`, `overloading`, `pair` |
| Patterns | `half_pyramid_num`, `half_pyramid_char`, `half_pyramid_alphabet`, `inverted_star_pattern`, `pascalTriangle` |
| Arrays | `array_create`, `reverse_arr`, `call_by_refernece_arr`, `removeduplicate`, `mergeSortedArray`, `sub_array` |
| Searching & sorting | `binary_search`, `search_in_rotated_sorted_array`, `basicSortingAlgorithm` |
| Subarray problems | `max_sum_subarray`, `prefix_sum_max_sum_subarray`, `kadanes_algorithm` |
| Two pointers & greedy | `containWithMostWater`, `trapping_rainwater`, `buy_sell_stocks` |

## Running a program

Each file is a standalone program:

```bash
javac kadanes_algorithm.java
java kadanes_algorithm
```
